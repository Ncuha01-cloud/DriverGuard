# DriverGuard — трекер глаз для водителя

Android-приложение, которое следит за лицом через фронтальную камеру и предупреждает водителя **до того, как он уснёт**.

[![Скачать APK](https://img.shields.io/badge/скачать-APK%201.0.0-22D3EE?style=for-the-badge&logo=android&logoColor=white)](https://github.com/Ncuha01-cloud/DriverGuard/releases/latest/download/app-release.apk)
[![Лицензия MIT](https://img.shields.io/badge/лицензия-MIT-22E3A0?style=for-the-badge)](LICENSE)

> [!WARNING]
> DriverGuard — вспомогательный инструмент, а не замена отдыху и внимательности. Он не управляет автомобилем, не заменяет автопилот и не гарантирует предотвращение ДТП. Все вычисления выполняются на устройстве, видео никуда не передаётся и не записывается.

---

## Проблема

Усталость за рулём — один из ведущих факторов тяжёлых ДТП: сонный водитель не тормозит, потому что продолжает «видеть дорогу» уже в микро-сне. Микро-сон длится 1–4 секунды, и при 90 км/ч этого достаточно, чтобы проехать **100 метров** с закрытыми глазами.

Человек не замечает момент, когда засыпает: собственная оценка усталости всегда завышена. Нужен внешний наблюдатель, который смотрит непрерывно.

## Что делает приложение

| Признак | Что измеряется | Порог (по умолчанию) |
|---|---|---|
| **Закрытые глаза** | EAR — Eye Aspect Ratio по контуру глаза из ML Kit | тревога при 1,1 с непрерывного закрытия |
| **Кивок головы** | угол Эйлера X относительно откалиброванного нейтра | тревога при 21° в течение 1,5 с |
| **Зевота** | раскрытие рта / ширина лица | предупреждение при > 0,42 |
| **Накопленная усталость** | скользящая средняя «плохого» поведения + число микро-снов | цвет кольца и шкала усталости |

Уровни реакции:

- **1** — мягкое предупреждение (глаза прикрыты, зевок, начало кивка);
- **2** — опасность (самая длинная фаза зевка / микро-сон);
- **3** — тревога: многотональная сирена 880/1320 Гц, громкость поднимается до максимума будильника, ритмичная вибрация, красный экран, который перекрывает даже блокировку экрана.

## Как это работает

```
CameraX (фронтальная камера, 480×640, YUV → Bitmap)
        │
        ▼
ML Kit Face Detection (16.1.7, bundled, CONTOUR_MODE_ALL)
   ├── контуры глаз ──► EAR (Eye Aspect Ratio) ──► адаптивный нормализатор
   ├── headEulerAngleX ──► кивок головы
   └── контуры губ ──► раскрытие рта (зевота)
        │
        ▼
DrowsinessEngine — детерминированное ядро (без Android-зависимостей)
   ├── гистерезис открыт/закрыт
   ├── таймеры удержания
   └── score усталости 0..1
        │
        ▼
MonitoringService (foreground, type=camera, PARTIAL_WAKE_LOCK)
   ├── уровень 1–2 ──► уведомление
   └── уровень 3 ──► AlarmPlayer + AlarmActivity
```

Ключевые решения:

- **EAR считается по контуру, а не по классификации ML Kit.** Встроенный `eyeOpenProbability` нестабилен на мелких лицах в машине, поэтому открытость глаз нормируется своей гистерезисной логикой с самообучением за первые ~10 секунд поездки.
- **Ядро детектора не зависит от Android.** `DrowsinessEngine` — чистый Kotlin: его можно прогнать тестами и объяснить пороги без эмулятора.
- **Кивок измеряется относительно калибровки.** Кнопка «Калибровать» берёт медиану наклона головы за ~4,5 секунды, поэтому высокий водитель и владелец низкого держателя получают одинаковое поведение.
- **Перекрытие интентов не считается усталостью.** Потеря лица дольше 2,5 с (взгляд в окно или зеркало) не поднимает тревогу, чтобы не срабатывать на нормальное вождение.
- **Сигнал синтезируется, а не берётся из рингтона.** WAV с частотной модуляцией собирается на устройстве и играет через `USAGE_ALARM` — тревога не зависит от того, что стоит на звонке у пользователя.
- **Видео не покидает телефон.** В приложении нет сети и аналитики; в истории сохраняются только длительность поездки и количество событий.

## Интерфейс

| Экран | Назначение |
|---|---|
| Приветствие | объясняет, зачем нужна камера, до запроса разрешения |
| Наблюдение | HUD поверх превью: рамка лица, якоря глаз, шкала наклона головы, кольцо бдительности, шкала усталости |
| Тревога | красный пульсирующий экран «ПРОСНИСЬ» с кнопкой «Я ПРОСНУЛСЯ» |
| Настройки | чувствительность одним ползунком (мапится в 6 порогов), громкость, вибрация, калибровка, тест сигнала, история поездок |

## Установка

### Вариант 1 — готовый APK (самый быстрый)

Скачайте **`app-release.apk`** со страницы [последнего релиза](https://github.com/Ncuha01-cloud/DriverGuard/releases/latest) — подписанный, 37,8 МБ, `minSdk 26`.

1. Рядом лежит `SHA256SUMS.txt`. По желанию сверьте сумму:
   `certutil -hashfile app-release.apk SHA256` (Windows) или `sha256sum -c SHA256SUMS.txt` (Linux/macOS).
2. Разрешите установку из этого источника и откройте файл.
3. Нужен телефон на Android 8.0+ с фронтальной камерой.

Прямая ссылка на файл:
`https://github.com/Ncuha01-cloud/DriverGuard/releases/latest/download/app-release.apk`

### Вариант 2 — собрать из исходников

Требования: JDK 17, Android SDK 34, эмулятор или телефон с Android 8.0 (API 26) и выше и фронтальной камерой.

```bash
git clone https://github.com/Ncuha01-cloud/DriverGuard.git
cd DriverGuard
# укажите путь к SDK в local.properties: sdk.dir=/path/to/Android/Sdk
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Либо откройте папку в Android Studio и нажмите Run.

Для собственной подписи релиза (`./gradlew assembleRelease`) нужен `keystore.properties` (не входит в репозиторий):

```properties
storeFile=keystore/release.jks
storePassword=***
keyAlias=***
keyPassword=***
```

### Первый запуск

1. Разрешите доступ к камере и уведомлениям.
2. Закрепите телефон в держателе так, чтобы фронтальная камера видела лицо.
3. Запустите поездку.
4. Откройте настройки → **Калибровать** и смотрите прямо 5 секунд.
5. Проверьте громкость: «Проверить, как срабатывает сигнал».

## Структура проекта

```
app/src/main/java/com/driverguard/eyetrack/
├── detection/DrowsinessEngine.kt   # ядро детектора: EAR, кивки, зевота, score
├── detection/FaceAnalyzer.kt       # обёртка ML Kit: контуры, углы головы
├── service/MonitoringService.kt    # foreground-сервис камеры и тревоги
├── alarm/AlarmPlayer.kt            # синтез сирены + вибрация
├── core/SettingsStore.kt           # настройки (DataStore)
├── core/SessionStore.kt            # локальная история поездок
├── ui/MainActivity.kt              # приветствие → наблюдение → итоги
├── ui/AlarmActivity.kt             # экран тревоги
├── ui/SettingsActivity.kt          # настройки и калибровка
└── ui/view/                        # HUD, кольцо бдительности, пульс тревоги
```

## Ограничения

- Работает только Android; iOS-версии нет.
- Требуется фронтальная камера и держатель — при сильной тряске лицо может теряться.
- Ночью, в темноте и в солнцезащитных очках точность EAR падает.
- Это open-source учебный проект, не медицинское изделие и не сертифицированный ADAS.
